# Food Delivery Analytics — Power BI Dashboard

## 1. Objective

Analyze food delivery operations, revenue, customer behavior, restaurant performance, and delivery efficiency using Power BI.

## 2. Key Performance Indicators

- **Total Revenue:** ₹2,905,823 in delivered revenue.
- **Total Orders:** 6,000.
- **Average Order Value:** Revenue divided by the applicable order count.
- **Total Customers:** Distinct customers represented in the model.
- **Cancelled Orders:** 458.
- **Average Delivery Time:** Approximately 57 minutes (56.88 minutes before rounding).

KPI values depend on the selected filters and the report's business definitions.

## 3. Dashboard Analysis

The report supports analysis of:

- Monthly order trends.
- Order status distribution.
- Customer and restaurant ratings.
- Average delivery time by month.
- Order cancellations and revenue performance.

## 4. Data Model

The report uses a dimensional model containing six dimensions and three fact tables. Date relationships and filter directions are designed to support consistent time-based analysis.

## 5. Business Value

The dashboard helps identify revenue trends, cancellation patterns, customer satisfaction, and delivery-efficiency issues. These insights can help operations teams prioritize improvements.

## 6. Technology

Power BI, Snowflake SQL, Fivetran, MySQL / Aurora RDS, Git, and GitHub.

## 7. Validation

The KPI values and chart logic were checked against the project report. Values may change when report filters or underlying data change.
